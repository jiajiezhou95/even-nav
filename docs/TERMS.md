Original source is provided under MIT without warranty. Map, geographic and transport data remain subject to the respective provider terms and attribution requirements. No guarantee is made of current train times, real-time delays, accurate entrances, driving safety or background execution.

The app recalculates routes; it does not import a Google Maps navigation session or promise the same train/alternative. Check actual signs, service information and surroundings. DRIVE exists for stationary replay and passenger-side evaluation before any real-world use. Stale location must suppress precise maneuver instructions; a suspended host cannot run a JavaScript watchdog.
